# 🧠 AlgoViz - Algorithm Visualization ArenaAlgoViz is an interactive educational platform that transforms complex algorithms into visual, competitive, and immersive learning experiences. Explore, compare, and master algorithms through real-time animations, step-by-step execution, and a futuristic cyberpunk interface.---## 🚀 Features## 🎯 Learning Realms### 🔢 Sorting Realm- **Algorithms:** Bubble, Merge, Quick, Heap, Insertion, Selection Sort  - **Features:** Watch algorithms race and compare performance live  - **File:** `sorting.html`### 🔍 Searching Zone  - **Algorithms:** Binary, Linear, Jump, Interpolation Search  - **Features:** Step-by-step visual comparison with custom data  - **File:** `searching.html`### 🌐 Graph City- **Algorithms:** BFS, DFS, Dijkstra, Kruskal  - **Features:** Build custom graphs and visualize pathfinding  - **File:** `shortestpath.html`### ⏱️ Time Complexity Arena- **Content:** 80+ MCQs with instant feedback  - **Topics:** Big-O, Omega, Theta notation analysis  - **File:** `time.html`### 📚 Asymptotic Notations- **Topics:** Big-O (O), Omega (Ω), Theta (Θ), Little-o  - **Features:** Growth rates and efficiency analysis  - **File:** `Notations.html`### 💻 Pseudocode Lab- **Features:** Control structures, loops & recursion, algorithm design  - **Learning:** Bridge logic to code with structured design  - **File:** `Pseudocode.html`### 🧩 Practice Arena- **Content:** 50 interactive algorithm challenges  - **Features:** Drag & drop code fragments, complexity analysis  - **File:** `Practice.html`### 🎓 Knowledge Test- **Content:** Concept-driven quizzes and algorithm design scenarios  - **Features:** MCQ battles, data structures, algorithm analysis  - **File:** `knowledgeTest.html`---## 🎮 Interactive Modes- **Auto Race:** Algorithms compete in real time  - **Step Mode:** Execute one step at a time  - **Custom Input:** Use your own data sets  - **Live Stats:** Track operations and performance metrics  ---## 🎨 Design & UX- Theme: Cyberpunk-inspired interface with animated grids  - Effects: Particle effects and glitch visuals  - Responsive: Fully responsive design for all devices  - Accessibility: No login required, instant access  ---## 🛠️ Tech Stack- **Frontend:** HTML5, CSS3, JavaScript (ES6)  - **Fonts:** Google Fonts (Orbitron, Inter, Fira Code)  - **Icons:** Font Awesome 6.5.0  - **Architecture:** Modular component-based design  ---## 📁 Project Structure
