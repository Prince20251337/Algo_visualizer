# Algo_visualizer

🧠 Overview

AlgoViz is an interactive platform that transforms algorithms into visual, competitive, and immersive experiences.

Explore, compare, and understand algorithms through real-time animations, step-by-step execution, and a futuristic cyberpunk interface.

🚀 Features
🔢 Sorting Realm

Bubble • Merge • Quick • Heap • Insertion • Selection
→ Watch algorithms race and compare performance live

🔍 Searching Zone

Binary • Linear • Jump • Interpolation
→ Step-by-step visual comparison

🌐 Graph City

BFS • DFS • Dijkstra • A*
→ Build custom graphs and visualize pathfinding

⏱️ Time Complexity Arena

→ 80+ MCQs with instant feedback

🧩 Practice Arena (Coming Soon)

→ Interactive drag-and-drop challenges

🎮 Modes
Auto Race — Algorithms compete in real time
Step Mode — Execute one step at a time
Custom Input — Use your own data
Live Stats — Track operations and performance
